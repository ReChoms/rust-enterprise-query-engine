Rust Enterprise Query Engine — Global System Blueprint

This document provides the high-level systems architecture specification for the Rust Enterprise Query Engine.

1. Ingress Flexibility ($O(1)$ Stream Processing)

The query engine supports three interchangeable ingress channels:

  • Interactive CLI: rust-enterprise-query-engine ask "Query"
  • Unix STDIN Streaming: cat queries.txt | rust-enterprise-query-engine ask with $O(1)$ flat memory consumption.
  • Axum REST Microservice: High-throughput HTTP endpoints on port 8080.

2. Dual-Engine Architecture

Queries are classified into two deterministic execution paths:

  • Analytical SQL Engine (src/sql_engine.rs): Zero-copy Apache DataFusion executing over Apache Arrow 51 dataframes with AST security checks.
  • Neural Semantic Engine (src/vector_db.rs & src/embeddings.rs): In-process Candle BERT embeddings + LanceDB 0.15 with anti-hallucination verification.

3. Kubernetes Cloud Orchestration

Deployable as a dual-container Pod where the lightweight Rust binary runs alongside an Ollama LLM sidecar over kernel loopback (localhost:11434), with durable LanceDB volume mounts.
